# Data

`glove-50k-100d.npz` holds the 50,000 most common words from the GloVe 6B word vectors (100 numbers per word), stored as 16-bit floats to keep the file small. It is used in session 4, Part 6.

- `words`: the words, most common first
- `vectors`: one row of 100 numbers per word

GloVe: Jeffrey Pennington, Richard Socher and Christopher D. Manning, 2014. *GloVe: Global Vectors for Word Representation.* https://nlp.stanford.edu/projects/glove/
